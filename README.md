## 🎯 Общее описание

Telegram-бот для знакомств с интеллектуальным подбором партнеров на основе психологической совместимости. Основные функции:

- **Регистрация профиля** с базовой информацией
- **Психологический тест** из 20-30 вопросов
- **Умные рекомендации** с процентом совместимости
- **Speed Dating** - 5-вопросное мини-знакомство
- **Обмен контактами** при успешном прохождении

## 👤 Что видит пользователь

### 2.1 Регистрация
- Команда `/start` → приветствие + кнопка "Заполнить профиль"
- Пошаговое заполнение: имя, возраст, город, пол, фото, никнейм
- Предложение пройти психологический тест

### 2.2 Психологический тест
- 20-30 утверждений с оценкой от 1 до 5
- Пример: "Мне легко знакомиться с новыми людьми"
- Результат: психологический портрет и готовность к рекомендациям

### 2.3 Лента рекомендаций
- Карточки пользователей: фото, имя, возраст, город, % совместимости
- Кнопки: ❤️ Лайк, ❌ Дизлайк

### 2.4 Speed Dating
- Уведомление о взаимном лайке
- 5 вопросов с поочередными ответами
- Возможность дизлайка в любой момент
- Обмен контактами при успешном завершении

### Процесс Speed Dating
```mermaid
flowchart TD
    StartSpeedDating[Запуск Speed Dating] --> Notify[Уведомление второму пользователю]
    Notify --> Consent{Согласие на участие?}
    
    Consent --> |Нет| Cancel[Отмена]
    Consent --> |Да| StartDialog[Начало диалога]
    
    StartDialog --> Q1[Вопрос 1]
    Q1 --> AnswerA1[Ответ пользователя А]
    AnswerA1 --> ShowA1[Показать ответ пользователю Б]
    ShowA1 --> AnswerB1[Ответ пользователя Б]
    AnswerB1 --> CheckStop1{Проверить дизлайки}
    
    CheckStop1 --> |Есть дизлайк| StopDialog[Остановить диалог]
    CheckStop1 --> |Нет дизлайков| Q2[Вопрос 2]
    
    Q2 --> MoreQ[...]
    MoreQ --> Q5[Вопрос 5]
    Q5 --> Success[Успешное завершение]
    
    StopDialog --> NotifyStop[Уведомление об остановке]
    Success --> ExchangeContacts[Обмен контактами]
```

### Обработка запросов и БД
```mermaid
sequenceDiagram
    participant U as User
    participant B as Bot Controller
    participant S as State Manager
    participant DB as Database
    participant M as Matching Service

    U->>B: /start command
    B->>S: Get user state
    S->>DB: SELECT state FROM users
    B->>U: Send registration form
    
    U->>B: Submit profile data
    B->>DB: INSERT INTO profiles
    B->>DB: UPDATE users state
    
    U->>B: Start psychological test
    loop 20-30 questions
        U->>B: Send answer
        B->>DB: Save answer
    end
    
    B->>DB: Save test results
    U->>B: Request recommendations
    B->>M: Get matches
    M->>DB: Query compatible users
    M->>B: Sorted recommendations
```
